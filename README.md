# Eva Sasvari, Portfolio

Static site. Upload the contents of this folder to a GitHub repository and enable
GitHub Pages (Settings, Pages, Deploy from branch, root).

Files
- index.html, the home page
- project-01.html, Peoplebase
- project-02.html, Little Trees Christmas Experience
- project-03.html, User research for a hair care app
- support.js, page runtime, must stay next to the HTML files
- img/, page images
- files/, CV PDF

Nothing else is required. All links, anchors, animations, the Figma embed and the
CV download work from the folder as-is.
